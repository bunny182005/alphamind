# Architecture Overview

AlphaMind AI operates as an asynchronous, multi-agent financial intelligence framework built on LangGraph and FastAPI.

## High-Level Topology
1. **Analyst Guild**: Fundamental, Sentiment, News, and Technical analysis run concurrently.
2. **Adversarial Debate Arena**: Bullish vs Bearish researchers execute multi-round structured debates.
3. **Execution & Risk Council**: Trader and Risk Manager synthesize signals to produce portfolio orders.
